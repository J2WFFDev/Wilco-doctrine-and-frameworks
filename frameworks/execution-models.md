## Purpose

This framework defines the theoretical models behind how execution unfolds in time during a SASP stage. Understanding these models is required for coaches and athletes to make sense of why certain techniques are faster, why certain mistakes happen, and how to design drills that target the right component.

The execution model concepts in this document form the "why" behind the technical cues found in the [SASP Performance Framework](steel-performance-framework.md).

---

## Two Execution Models

### Serial Execution

In serial execution, each task is completed before the next task begins.

```
[Prep]  →  [Fire]  →  [Assess]  →  [Transition]  →  [Prep]  →  [Fire]
```

Characteristics:
- One cognitive or mechanical process at a time
- Lower cognitive load
- Slower overall execution
- Appropriate for: **Foundation-level athletes**, new skills, under stress

Common serial execution patterns:
- Fire → confirm hit → decide to transition → move muzzle
- Present to target → establish sight picture → prep trigger → fire
- Complete shot → reset trigger to rear → then reset to prep position

**Serial execution is not wrong.** It is developmentally appropriate at the Foundation stage and is the correct starting point for any new skill. The error is staying serial longer than development requires.

---

### Parallel Execution

In parallel execution, multiple tasks overlap in time. One process begins before the previous one fully completes.

```
[Fire]
       [Assess while transitioning]
              [Prep trigger during muzzle movement]
                     [Establish visual lead before muzzle arrives]
                            [Fire]
```

Characteristics:
- Multiple cognitive or mechanical processes overlap
- Higher cognitive demand — requires internalized sub-skills
- Faster overall execution
- Appropriate for: **Intermediate and Senior athletes** with established fundamentals

Common parallel execution patterns:
- Reset trigger during recoil (not after)
- Begin muzzle transition during shot assessment (not after)
- Eyes arrive on next target before muzzle does (visual lead)
- Stage plan is active during prior string (cognitive parallel)

**Parallel execution requires that each individual sub-skill is well-established before it can be overlapped.** Attempting to parallelize underdeveloped skills accelerates error, not speed.

---

## Cognitive vs. Mechanical Overlap

Execution tasks can be divided into two categories:

| Type | Examples |
|------|---------|
| **Mechanical** | Trigger press, muzzle movement, stance, grip, recoil management |
| **Cognitive** | Target selection, hit assessment, transition decision, stage plan execution |

### Key Insight: Cognitive Overlap

The first task that can be parallelized is cognitive, not mechanical. An athlete can begin planning the next target or assessing a hit *while the mechanical process of the current shot is still completing.*

This is a major leverage point in development:
- Athletes who learn to **assess while the gun is still moving** compress split times significantly
- Athletes who **hold the stage plan in working memory** move more efficiently between strings
- Athletes who **pre-load the next transition** during the current shot complete stages faster

Coaching priority: **Build cognitive overlap before building mechanical overlap.**

## Prep During Movement

One of the highest-value parallel skills in SASP:

> **Trigger prep occurs during muzzle transition, not after muzzle arrival.**

In serial execution:
```
Muzzle arrives → trigger takes up slack → fire
```

In parallel execution:
```
Muzzle moving → trigger prepping simultaneously → fire as muzzle arrives
```

The result: the shot breaks the moment the muzzle confirms on target, rather than after a full trigger prep sequence begins. This is a fundamental split-time compression technique.

**Prerequisites for this skill:**
- Clean, consistent presentation mechanics
- Reliable trigger prep pressure that does not disturb sight alignment
- Strong target geometry internalization (so the athlete knows when the muzzle is "there")

## Compressed Timing

Compressed timing is the cumulative result of multiple parallel execution elements occurring simultaneously.

Each parallel technique adds a small time savings. Combined, the effect is substantial:

| Technique | Approximate Time Compression |
|-----------|------------------------------|
| Visual lead (eyes before muzzle) | 0.05–0.15 sec per transition |
| Prep during movement | 0.05–0.10 sec per shot |
| Trigger reset during recoil | 0.03–0.08 sec per shot |
| Cognitive transition pre-load | Variable — eliminates decision hesitation |

These numbers are illustrative. Actual gains depend on athlete, stage layout, and equipment.

## Development Progression

| Stage | Execution Model | Focus |
|-------|----------------|-------|
| **Foundation** | Serial | Build clean mechanical sub-skills one at a time |
| **Intermediate** | Serial → Early Parallel | Begin overlapping cognitive tasks; introduce visual lead |
| **Senior** | Parallel | Mechanical overlap, prep-during-movement, compressed timing |

**Rule:** Never push an athlete toward parallel execution before the underlying sub-skills are clean. Parallel execution on a broken foundation produces consistent errors, not consistent speed.
