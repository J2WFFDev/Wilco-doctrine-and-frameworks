# Steel Challenge Performance Framework

> **Canonical terminology reference:** [doctrine/terminology.md](../doctrine/terminology.md)

---

## Purpose

This framework defines how Wilco Shooting Sports structures the development, measurement, and improvement of Steel Challenge performance. It provides coaches and athletes a common language, a shared execution model, and a structured approach to analysis and drill design.

---

## Execution Model

Steel Challenge performance is built on three interconnected components:

```
PRESENTATION → TARGET ENGAGEMENT → TRANSITION
```

Each component has defined sub-skills and measurable outputs.

### Presentation
- Draw to first shot (or low-ready to first shot)
- Grip establishment
- Sight alignment at presentation
- Shot break quality on first target

### Target Engagement
- [Confirmed execution](../doctrine/terminology.md#confirmed-execution) vs. [predictive execution](../doctrine/terminology.md#predictive-execution)
- [Shot calling](../doctrine/terminology.md#shot-calling) accuracy
- [Trigger prep](../doctrine/terminology.md#trigger-prep) and [trigger reset](../doctrine/terminology.md#trigger-reset) consistency

### Transition Efficiency
- Muzzle path (direct line vs. arc)
- Visual lead (eyes arrive before muzzle)
- Split time between shots on different targets

## Run Classification

All stage runs are classified using the following system. See [terminology.md](../doctrine/terminology.md) for full definitions.

| Classification | Description | Use |
|----------------|-------------|-----|
| **Clean Run** | All hits, consistent process, no errors | Model to replicate |
| **Sloppy Run** | All hits, inconsistent process | Fast but unreliable; identify cause |
| **Recovery Run** | Error occurred; successful correction made | Evaluate recovery quality |
| **Miss Run** | One or more targets not hit | Identify whether cause was technical, mental, or environmental |

### Run Review Protocol
After every string:
1. Call the string (hits/misses, felt quality)
2. Identify which classification applies
3. State the one most important variable that produced the result
4. Decide: repeat same intent, or adjust one variable

## Performance Components

### Technical Components
- Draw / presentation speed and consistency
- First-shot accuracy (hit rate on first shot attempt)
- Split times within target array
- Transition times between targets
- Stop plate hit rate and timing

### Mental Components
- Pre-string routine consistency
- [Shot calling](../doctrine/terminology.md#shot-calling) accuracy (call vs. result)
- Response to misses (recovery quality)
- Stage preparation thoroughness

### Physical Components
- Stance stability
- Grip pressure consistency
- Recoil management
- Endurance over multi-string stages

## Drill Design Structure

All Steel drills in the [drill catalog](../drills/steel-drill-catalog.md) follow this structure:

| Field | Description |
|-------|-------------|
| **Drill Name** | Short, descriptive name |
| **Target Component** | Which performance component(s) this drill develops |
| **Setup** | Target positions, distances, starting position |
| **Procedure** | Step-by-step execution instructions |
| **Metric** | What is measured (time, hit rate, split, etc.) |
| **Standard** | Target metric for each development stage |
| **Notes** | Coaching cues, common errors, scaling options |

## Environment and Bio-Condition Tracking

Performance variance is often environmental or bio-condition driven, not technical. Track and log:

### Environmental Factors
- Temperature and humidity
- Lighting conditions (shade, sun angle, glare)
- Wind (affects stance, target visibility)
- Stage surface (grip, footing)

### Bio-Condition Factors (see [terminology.md](../doctrine/terminology.md#bio-condition))
- Sleep quality (prior night)
- Nutrition and hydration status
- Stress level (external)
- Physical readiness (injury, fatigue)

### Logging Protocol
Log bio-condition and environmental conditions at the start of each training session and each match. This data is used to interpret performance outliers.

## Equipment and Metrics Logic

### Equipment Baseline
Establish a consistent equipment baseline for each athlete before tracking performance data. Changes to any of the following variables should be logged and treated as potential performance factors:

- Firearm (make, model, caliber)
- Ammunition (brand, load, bullet weight)
- Holster (type, retention, position)
- Optic or sights (type, height over bore)
- Trigger (pull weight, reset distance)

### Metrics Hierarchy

| Tier | Metric | What It Tells You |
|------|--------|-------------------|
| 1 | Stage time | Overall outcome |
| 2 | String times | Consistency across strings |
| 3 | Split times | Within-target engagement speed |
| 4 | Transition times | Between-target movement efficiency |
| 5 | First-shot hit rate | Presentation quality |
| 6 | Stop plate hit rate | Stage completion reliability |

Lower tier numbers reflect outcome metrics. Higher tier numbers reflect process metrics. **Process metrics drive outcome metrics.** Coach focus should be on Tiers 3–6 first.
