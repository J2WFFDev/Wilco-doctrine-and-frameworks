## Role of the Range Safety Officer

The Range Safety Officer (RSO) is the safety authority on any active range. The RSO is not a scorekeeper, a coach, or a spectator. During any active firing line, the RSO's primary responsibility is safety — for athletes, coaches, spectators, and themselves.

## Range Commands

> *Reference:* [operations/match-operations.md](../operations/match-operations.md) contains the full command sequence. The RSO Guide summarizes authority and coaching context; Match Operations owns the procedures.

| Command | When Used |
|---------|-----------|
| "Load and Make Ready" | Competitor may prepare to shoot |
| "Are You Ready?" | Confirm readiness before start signal |
| "Standby" | Start signal imminent |
| *[Start Signal / Beep]* | Begin shooting |
| "**STOP**" | Immediate cease fire — all situations |
| "Unload and Show Clear" | After string completion |
| "Hammer Down, Holster" | Final step before clearing the line |
| "Range is Safe" | Safe to handle targets |

## Safety Intervention Authority

The RSO has authority to:

- Call STOP at any point for any safety concern, without explanation
- Remove a shooter from the line for a safety violation
- Refuse to start a string if the range is not safe
- Escalate to the Match Director for rule interpretations

The RSO does **not** have authority to:
- Override a Match Director's ruling on rules interpretations
- Accept a reshoot request — that decision belongs to the Match Director
- Coach the athlete on performance during competition (safety corrections only)
