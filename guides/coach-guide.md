# Coach Guide

> **Canonical terminology reference:** [doctrine/terminology.md](../doctrine/terminology.md)

---

## Role of the Coach

The coach is the architect of the athlete's development environment — not a result-manager or a cheerleader. The coach:

- Designs practice with purpose
- Gives feedback that is specific, observable, and actionable
- Teaches the athlete to self-assess
- Holds the standard with consistency and patience
- Represents the program in every interaction

---

## Session Planning

Every training session should have:

1. **Defined objective** — What specific performance component is being developed?
2. **Drill selection** — Which drills from the [drill catalog](../drills/steel-drill-catalog.md) target that component?
3. **Measurement method** — How will progress be observed and recorded?
4. **Review plan** — How will the session be closed and what will athletes log?

Avoid "just shooting." Unstructured repetition builds inconsistency.

---

## Giving Feedback

Effective feedback is:

- **Specific** — "Your trigger finger was moving before the sight was on target" is useful. "Be more careful" is not.
- **Observable** — Based on what you saw, not what you assumed.
- **Actionable** — The athlete must be able to do something different with the feedback.
- **Timely** — Given immediately after the observable event when possible.

**Feedback cadence:**
- Give feedback on one thing at a time. More than one change creates cognitive overload.
- Confirm the athlete understood by asking them to restate it.
- Follow up in the next string — did the behavior change?

---

## Using the PARR Cycle

Structure every drill iteration around [PARR](../doctrine/terminology.md#parr):

| Phase | Coach Action |
|-------|-------------|
| **Prepare** | Confirm the athlete has a plan before approaching the line |
| **Act** | Observe, do not interrupt |
| **Review** | Ask the athlete to self-assess first, then add your observation |
| **Repeat** | Confirm the intent for the next string |

The goal is to make the athlete do the PARR cycle independently. Eventually they should not need you to prompt it.

---

## Performance Review

After every match, conduct a structured review:

1. Have the athlete classify each run (clean, sloppy, recovery, miss)
2. Ask: "What was the cause of the result on that string?"
3. Identify the single highest-leverage variable to adjust
4. Set the intent for the next training session

Avoid post-match conversations that are only emotional or only outcome-focused. Bring both in balance.

---

## Parent Communication

- Communicate proactively. If an athlete is struggling, parents should hear it from you before they hear it from the athlete.
- Keep parent feedback conversations separate from athlete training time.
- Be consistent in messaging between what you tell the athlete and what you tell the parent.
- If a parent is interfering with athlete development (sideline coaching, outcome pressure), address it directly and early. See [guides/parent-guide.md](parent-guide.md).

---

## Document and Record Keeping

- Log each athlete's session performance notes
- Track OKR progress across the season
- Note equipment changes and their effect on performance
- Maintain safety incident records per [operations/safety-manual.md](../operations/safety-manual.md)

### Key Concepts for Coaches

**Two distinct transition components — know the difference:**
- **First-Target Acquisition Time ("1st shot time"):** Beep → first shot break, from low ready. Contains reaction time + presentation + trigger press. This is the first and most accessible place to find time in a clean run. Coaching it means understanding all three sub-components separately.
- **Inter-Target Transition Time (ITT):** Shot break on Tₙ → shot break on Tₙ₊₁. Contains lateral movement, recoil management, possible direction reversal, impact confirmation, and trigger cycle. Sub-components are hard to isolate individually — treat ITT as an aggregate that is averaged across multiple runs and both directions.

**Split time is context-dependent:**
In Test 1 (rapid fire, single target), the split time is a pure trigger press cycle — engage, wall, prep, break, reset. In any context involving transitions, the split between shots also includes whatever happened between them. Always interpret split time relative to what the athlete was doing.

**Two trigger methods — both are valid:**
- *Wall-Prep-Break-Reset:* Deliberate, staged approach. Appropriate for developing athletes or confirming-execution scenarios.
- *Rolling trigger:* Continuous smooth press through — higher pace, requires a well-developed feel. Used by experienced athletes in predictive-execution mode.
Coaching trigger method selection requires understanding the athlete's current level and the tactical context of each shot.

**Stage preparation in SaSP:** Athletes do not stage walk. The equivalent is **6 unloaded sight pictures** before each string. Coach athletes to use this time intentionally: establish the sight picture on each target in order, confirm foot position, and load the mental plan.

**On-deck readiness is a performance input:** What an athlete does while waiting to shoot affects the next string. Coach athletes to use the window — airgun practice, visualization, or deliberate relaxation. Disengagement or anxious distraction is a coachable behavior.

**Between-string behavior matters:** The window between strings is a performance tool. Evaluate whether the athlete is using it for momentum, evaluation, or necessary rest — and whether that choice was appropriate for the moment.

**Mulligan management (rimfire only):** A mulligan exists to address ammo inconsistency — not shooter-induced malfunctions. Coaching mulligan management means helping athletes evaluate: Was the request appropriate? Did they attempt to clear and continue? Was there intel from the gun's post-malfunction behavior? Is retaining a good run the right risk-reward call? RSOs and coaches may assist with the evaluation.

**Coaching findings taxonomy (for session notes):**
- ~80%: repeatable mistakes with known corrective practice actions (primary coaching workload)
- small subset: advanced/rare/unique technique findings
- small subset: equipment-behavior findings (springs, extractor/cycling issues, etc.) tied to equipment fault tracking
- very rare: master-level outside-the-box insights

Use this taxonomy in post-session notes so common corrective actions stay actionable while rare findings are still captured.
