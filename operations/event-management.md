# Event Management

> **Canonical terminology reference:** [doctrine/terminology.md](../doctrine/terminology.md)
>
> **Purpose:** This document is the master reference for all event types at Wilco Shooting Sports. Each event type has its own operational profile — required roles, setup requirements, safety requirements, and operational procedures. Use this document to understand what system to follow for any Wilco event.

---

## Event Type Catalog

| Event Type | Description | Operational Reference |
|------------|-------------|----------------------|
| **Practice Session** | Regular training session at the range | This document — Section: Practice Session |
| **Internal Match** | Team-only scored competition | This document — Section: Internal Match |
| **Hosted Competition** | External competitors invited; Wilco runs the match | [operations/match-operations.md](match-operations.md) + [operations/match-director-guide.md](match-director-guide.md) |
| **Away Match** | Wilco athletes competing at an external event | This document — Section: Away Match |
